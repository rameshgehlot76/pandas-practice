Hands-on practice files from learning **pandas** for data analysis and AI/ML — covering DataFrame basics, exploration, filtering, modification, and reading/writing data in multiple formats.

## Tech Stack

| Tool | Purpose |
|------|---------|
| Python 3 | Core language |
| pandas | Data manipulation & analysis |
| JSON / CSV / Excel | Data file formats practiced |

## Project Structure 

```
pandas-practice/
└── pandas/
    ├── topic.py           # shape and columns

    ├── examplestep5.py      # selecting single/multiple columns

    ├── output.json           # sample generated output
    ├── app.py                # reading data from Excel

    ├── output.csv            # sample generated output
    ├── output.xlsx           # sample generated output
    └── SampleSuperstore.xlsx # practice dataset
```

## How It Works

Each file is a focused, self-contained script covering one pandas concept — DataFrame creation, exploration (`shape`, `columns`, `info()`, `describe()`), selection and filtering, adding/updating/removing columns, and reading/writing CSV, JSON, and Excel files.

## What I Learned

- Core pandas structures: `Series` and `DataFrame`
- Exploring datasets before analysis (shape, columns, dtypes, nulls)
- Selecting and filtering data with boolean indexing
- Adding, updating, and removing columns
- Reading and writing CSV, JSON, and Excel files
